# ThriftEX Cleaning Robot

Lore-friendly robot vacuum and dock props for FiveM, featuring ThriftEX (GTA branding).   
**Nothing special, but it does looks good in game 😊**

## Previews

![All props](https://r2.fivemanage.com/cSLjIkKVIp1MD8BFZ9U1L/prop_cleanrobot_props.png)

## Model names and hashes

- `prop_cleanrobot` - `0x41B63143` (Standalone robot)
- `prop_cleanrobot_small` - `0xCD85E460` (Standalone small robot)
- `prop_cleandock` - `0x1CA8AC19` (Small dock, empty)
- `prop_cleandock_small_occupied` - `0x52D5D714` (Small dock with robot)
- `prop_cleandock_tall` - `0xF7A4B39F` (Tall dock, empty)
- `prop_cleandock_tall_occupied` - `0xDFC7529D` (Tall dock with robot)

## Colours

All six models share the same tint indices. On occupied models, the dock and robot change colour together.

- `0` - White (`#DBDCDE`)
- `1` - Black (`#262729`)
- `2` - Silver (`#BABDC2`)
- `3` - Blue (`#52AEDB`)
- `4` - Green (`#29CF31`)
- `5` - Orange (`#D69A29`)
- `6` - Pink (`#DE82DB`)
- `7` - Purple (`#BDA6C8`)
- `8` - Red (`#B5413F`)
- `9` - Yellow (`#EFC339`)
